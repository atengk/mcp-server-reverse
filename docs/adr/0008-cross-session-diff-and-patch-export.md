# 0008. 跨会话二阶结构化差异画像与虚拟补丁安全导出

- **状态**: accepted

## 背景与问题

随着静态逆向分析深度的推进，分析人员与自动化 Agent 经常面临两大现实挑战：

1. **虚拟修改难以安全固化与下游交付**：
   既有系统通过写时复制（COW）内存覆写层支持了安全的 What-If 假设推演，但分析人员验证成功后（如通过打补丁成功绕过反调试或证书校验），无法将已打补丁的镜像直接安全落地为磁盘文件供动态调试或环境验证；如果直接导出，若缺乏严密的路径防御容易发生自毁式覆写源样本文件（破坏数字取证第一现场）或越界写入高危系统目录。
2. **变种木马与 1-Day 漏洞分析缺乏量化比对能力**：
   当面对同家族的两个恶意变种样本、或者针对同一组件修补前后的两个二进制时，分析人员必须分别开启两个会话并人工对比大量节区、导入表与函数列表；缺少自动化同源度量机制与二阶结构化差异比对工具，传统的基于控制流图（CFG）图同构匹配算法计算开销极高且难以处理重定位和重编译变动，导致 AI Agent 消耗巨额 Token 也无法迅速锁定关键补丁代码。

## 决策

1. **写时复制覆写层穿透与防自毁安全导出 (`export_patched_binary`)**：
   - 在会话层提供 `export_patched_bytes()` 接口，以流式分块读取有效字节并透明穿透叠加全部激活补丁；
   - 在 `SecurityGuard.validate_output_file` 中设立安全校验门禁：
     1. 严格要求目标输出路径必须位于 `allowed_dirs` 白名单目录内；
     2. 严格比对输出绝对路径与会话源文件物理绝对路径，若同名覆写立即拦截并抛出 `FORBIDDEN_OVERWRITE_ORIGINAL` 错误，从根源消除源样本被篡改的风险；
     3. 在 Linux/macOS 类 Unix 平台上通过 `os.stat` 与 `os.chmod` 自动继承源文件的执行权限位（R/W/X），确保导出的二进制可直接执行。
2. **基于 SSDEEP 模糊哈希的轻量同源相似度度量 (`similarity_score`)**：
   - 摒弃耗时极高且脆弱的全局函数控制流图同构 AST 比较，采用纯 Python 实现的标准 SSDEEP 上下文触发分段哈希（CTPH）算法；
   - 提取双方会话的模糊哈希（若有激活补丁则基于导出镜像动态计算），依据标准分块步长与 Levenshtein 编辑距离进行归一化比较，输出 0~100 相似度量化分值。
3. **二阶结构化跨会话差异画像 (`BinaryDiff` / `diff_sessions`)**：
   - **基础架构与漏洞缓解对比**：对比双方格式、架构、位宽、端序与文件尺寸差值，并对比全平台缓解机制加固评分变化与具体开关变动；
   - **节区拓扑与香农熵差异**：对齐双方节区，计算虚拟大小与文件尺寸差值，计算每个对应节区的香农熵变动量（`entropy_delta`），并自动高亮新增的异常高熵节区；
   - **导入导出敏感行为 API 差集**：计算增删与保留的 API 集合，自动标记涉及进程注入、反调试、网络外联的高危行为分类标签；
   - **符号与代码重定位偏移推导**：对齐公共函数符号，基于众数统计算法自动推断代码段虚拟地址重定位基址偏移，并统计各自独有的内部函数列表。
